\frame{\titlepage}
\begin{frame}{Question}How much task accuracy can be preserved when a mobile-edge system sends semantic features rather than raw features?\end{frame}
\begin{frame}{Prototype}64-dimensional features are compressed to 8 dimensions and transmitted over Rayleigh fading.\end{frame}
\begin{frame}{Seeded result}At 2 dB: semantic accuracy 90.83\%, raw baseline 100\%, dimension ratio 12.5\%.\end{frame}
\begin{frame}{Scope}This is a PCA baseline, not a final Deep JSCC claim. Public image/task data and learned training are next.\end{frame}
